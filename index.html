About

A developer with a designer's eye.

I studied Computer Science and Design, which meant learning how interfaces are drawn and how they are built at the same time. That is still how I work — I sketch a flow in Figma, then think about what the components and the API response need to look like for it to exist.

On the design side I work in Figma: research, wireframes, prototypes and interface design, with accessibility and readability treated as requirements. On the development side I build responsive frontends with HTML, CSS and JavaScript, and server-side applications with Python and Django, including REST API endpoints and MySQL databases.

I'm early in my career and still learning quickly. What I offer now is someone who takes a design handoff seriously in both directions.
